# NODE QUEST

体力を配分して工房を組み、無限ダンジョンをどこまで潜れるかを競う放置RPG。

**▶ 遊ぶ: https://y-num.github.io/node-quest/**

---

## テストプレイをしてくださる方へ

遊んでいただくのは上のURLだけで大丈夫です。インストールは要りません。

### セーブについて（お願い）

セーブは**ブラウザの中**に5秒ごと自動保存されます。サーバーには送っていないため、いくつか消えてしまう条件があります。

- **iPhone / iPad の方は「ホーム画面に追加」してください。**
  Safari は7日間サイトを開かないと保存データを自動削除します。ホーム画面から起動すれば対象外になります。
- **シークレット（プライベート）モードでは保存されません。** 通常のタブで開いてください。
- **端末やブラウザを変えるときは、画面上部の「引き継ぎ」ボタン**でコードをコピーして控えてください。
  移行先で同じボタンを開き、コードを貼って「読み込む」で続きから遊べます。念のための控えとしても使えます。

ゲーム側を更新してもセーブは消えません。安心して遊び続けてください。

### 見てほしいところ

- どこで手が止まったか、何が分からなかったか
- 「もう十分やった」と思って閉じたときの**最深到達層**
- 放置して戻ってきたときの手応え

気づいたことは何でも教えてください。

## 遊び方

1. **⚡体力がすべての元。** 勇者（拠点）から出る体力を、どのノードに何本配線するかがそのまま配分になります。
2. **緑の丸（出力）を相手の青い角（入力）へドラッグ**して繋ぎます。素材ごとに口が分かれています。
3. **採掘・精錬・鍛造は必ず廃材を出します。** 廃棄場に体力と廃材を送らないと、バッファが埋まって工房全体が止まります。
4. **🏋️筋トレ・📖読書・🏃走り込み**で能力を上げます。鍛えるほど1回に必要な体力が増えます。
5. **🧠知力が上がると未知のノードが「判明」**します。それを🔬研究所で開発すると建設できるようになります。
6. **🚪ダンジョンに潜って深さを稼ぎます。** 10層ごとの踏破で攻撃力が恒久的に上がり、留守中の報酬も伸びます。

配線はドラッグすると中継点ができて経路を整理でき、クリックで切断、中継点をダブルクリックで直線に戻せます。
ノードが見つからなくなったら上部の「全体表示」か「整列」を押してください。

## 開発メモ

- 単一HTML・外部依存ゼロ。`index.html` を開けばそのまま動きます
- 成長曲線はスクリプト冒頭の `CURVE = { index, taper, depth }` の3値だけで調整できます（現行が100）
- セーブキーは `nodequest` で固定。構造を変えるときは `SAVE_V` を上げて `migrate()` に処理を足してください。
  **キーごと変えるとテスターのデータが消えます**
- 配布URLのオリジン（`https://y-num.github.io`）を変えるとセーブは全消しになります
